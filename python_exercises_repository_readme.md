# Python Programming Exercises Repository

This repository contains my solutions and expanded versions of exercises from the book *Python Programming Exercises, Gently Explained* by Al Sweigart.

Book Website:
https://inventwithpython.com/pythongently/

---

# Purpose

The purpose of this repository is to learn Python through hands-on programming exercises while gradually improving each solution beyond the original requirements.

Rather than only completing the exercises exactly as written, many programs are expanded with additional features and improvements such as:

- Interactive user input
- Input validation
- Automated testing
- Decimal arithmetic
- Proper rounding
- Cleaner formatted console output
- Improved program structure
- Better error handling
- More scalable testing methods

This repository also serves as a way to practice:

- Core Python programming
- Problem solving
- Writing reusable functions
- Exception handling
- Numeric precision
- Console application design
- Git and GitHub workflows
- Writing technical documentation

---

# Repository Structure

Each exercise has its own directory containing:

- One or more Python programs
- Variations and expanded versions
- A dedicated README explaining the exercise and improvements

Many exercises include multiple implementations that evolve from:

1. A basic solution
2. An interactive version
3. A Decimal-based version
4. A rounded Decimal version
5. Organized testing versions

# Running Programs

Run a Python file from the terminal:

```bash
python3 filename.py
```

Example:

```bash
python3 helloworld.py
```
